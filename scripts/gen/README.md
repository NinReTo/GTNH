# Генератор построек

Собирает `lib/gen-kinds.ts`, `lib/gen-machines.ts` и `scripts/gen-textures.json`
из исходников GT5-Unofficial (тег 5.09.54.265 — версия мода в сборке GTNH 2.9).

- `batches/*.cjs` — тексты, советы и ручные правки по каждой постройке. Это исходник: правки вносить здесь.
- `multi.cjs` — вынимает схему постройки и её блоки из класса контроллера.
- `blocks.cjs` — находит картинку блока по классу блока и номеру.
- `emit.cjs` — пишет файлы сайта. `labels-ru.json` — переводы подписей, которых нет в игре.

Скрипты ждут рядом (пути заданы в начале файлов): клон исходников мода в `../gt5src`,
языковые файлы мода в `../lang`, список картинок архива мода `../jar-pngs.txt`,
карточки вики `../audit-wiki.json` и русский файл игры `GregTech_ru_RU.lang`.
После `node emit.cjs` — `node scripts/fetch-textures.mjs gen`.
