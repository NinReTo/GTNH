# Паровая эра GregTech New Horizons — Minecraft 1.7.10

Сайт про первые машины мода GregTech в сборке GT New Horizons. Каждая
постройка — трёхмерная модель из настоящих блоков мода: её можно вертеть,
перетаскивая мышкой, а блоки рядом с курсором раздвигаются и показывают, из
чего она сложена.

- **Шапка главной** — «паровой цех»: все постройки на одном полу, камера
  медленно облетает их сама, мышкой цех можно повернуть, блоки у курсора
  раздвигаются. Расстановка — `WORKSHOP.layout` в `lib/config.ts`.
- **Главная** — лестница паровой эры: без энергии → одноблочные бронзовые
  машины → стальные «высокого давления» → многоблочные постройки → электричество.
  Постройки стоят в ней маленькими трёхмерными значками (все на одном общем
  холсте, компонент `View` из drei): под мышкой значок поворачивается и
  раздвигается, по клику открывается страница постройки.
- **Страница машины** (`/machines/<имя>`) — трёхмерная модель, рассказ простым
  языком, факты и схема состава с ползунком.

Постройки: кирпичная домна, коксовая печь, водяной бак (Railcraft, текстура
нарисована заново — см. NOTICE), паровые печь, плавильня сплавов,
дробилка, компрессор, молот, насос — и электрическая доменная печь как
следующий шаг после пара.

## Как устроено

- **Next.js (App Router), React, TypeScript, Tailwind CSS v4.**
- **React Three Fiber + drei + @react-three/postprocessing** — сцена.
  Свечение, разъезд каналов, зерно и тональная компрессия — готовые эффекты.
  Самописный шейдер один: переход сцены в страницу
  (`components/scene/TransitionEffect.ts`).
- **Вращение** — готовый `OrbitControls` из drei (приближение и сдвиг выключены,
  колесо мышки остаётся прокрутке страницы).
- **zustand** хранит два значения: положение прокрутки (ведёт переход к странице)
  и положение курсора над холстом (раздвигает блоки). Кадр рисуется только когда
  что-то из этого меняется или блоки ещё не доехали до места.

### Главное правило: все числа — в `lib/config.ts`

В компонентах, шейдере и схемах чисел нет. Каждое число в `lib/config.ts`
снабжено комментарием: почему именно столько и что сломается, если поставить
иначе. Правило проверяется тестом (`tests/rest.test.ts`, последний блок).

Исключения: 0, 1 и деление пополам в чистой арифметике, а также классы
Tailwind в разметке (`p-6`, `text-xs`) — это вёрстка, а не настройки сцены.

### Схемы не могут разойтись со сценой

Каждая схема на странице вызывает те же функции, что и сцена:

| Схема | Функция | Файл |
|---|---|---|
| Разбор постройки по блокам | `explodedPosition()` | `lib/structure.ts` |
| Фазы прокрутки | `phaseThresholds()` | `lib/scroll.ts` |
| Калькулятор нагрева | `heatCapacity()`, `heatBonuses()` | `lib/heat.ts` |

### Как добавить постройку

Все постройки описаны в `lib/machines.ts`. Схема (`layers`) записывается так
же, как в исходниках мода с `transpose(...)`: слои сверху вниз, строки от
фасада назад, символы слева направо; пробел — пусто, `~` — контроллер.
Если в исходнике схема без `transpose` (срезы от фасада назад), её нужно
переложить в слои — так сделано для дробилки и компрессора.

Куда какой блок раздвигается, считается само (`lib/structure.ts`): блок
уходит от оси постройки и вверх, но только туда, где свободно, — поэтому
раздвинутые блоки никогда не въезжают друг в друга. Это проверяется тестом
для каждой постройки.

### Откуда сведения о моде

Схемы построек, ярусы напряжения и формулы нагрева взяты из исходного кода
[GT5-Unofficial](https://github.com/GTNewHorizons/GT5-Unofficial): у каждой
машины на её странице есть ссылка на свой файл. Сведения об электрической
печи сверены с [вики GT New Horizons](https://wiki.gtnewhorizons.com/wiki/Electric_Blast_Furnace).
Код взят с ветки, на которой сейчас идёт 2.10; паровая эра там устроена так же,
как в 2.9.

## Как повторить замеры

Сервер разработки примерно вдвое медленнее сборки — мерить нужно только
собранную версию.

```bash
npm run build
```

```bash
npm run start
```

1. Откройте <http://localhost:3000/?bench>.
2. Нажмите «Замерить кадр» несколько раз — возьмите среднее значение.
3. Повторите с выключенными по одному частями: `?bench&off=bloom`,
   `?bench&off=chromatic`, `?bench&off=transition`, `?bench&off=shadows`,
   и со всем выключенным: `?bench&off=all`.
4. Внесите результаты в `PERF.measured` в `lib/config.ts` — график на странице
   строится из них.

Кнопка рисует 120 кадров подряд и после каждого читает один пиксель: это
заставляет видеокарту действительно закончить кадр. Тени при этом
перерисовываются на каждом кадре — меряется худший случай, когда блоки
двигаются. Ещё две ручки для опытов: `&msaa=0` (сглаживание) и `&dpr=0.7`
(плотность пикселей).
